# HexaClaim — Medical & Pharmacy Billing Solutions

> **Official Website:** [HexaClaim.com](https://hexaclaim.com)

## 💻 Getting Started Locally

No build tools or node dependencies required. Simply open `index.html` in any modern web browser or serve via any static file server:

```bash
# Option 1: Direct browser opening
open index.html # On macOS
start index.html # On Windows

# Option 2: Using Python's built-in server
python -m http.server 3000
```
